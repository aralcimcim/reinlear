# Reinforcement Learning

My reinforcement learning coursework on bandit algorithms, dynamic programming, Monte Carlo methods, temporal-difference learning, and policy gradients.

## Contents

| Folder | Topics |
|---|---|
| [as_0](as_0/) | Expected values, random simulation, discounted returns, and an introduction to Gymnasium |
| [as_1](as_1/) | Multi-armed bandits: ε-greedy exploration, optimistic initial values, UCB, gradient bandits, and nonstationary rewards |
| [as_2](as_2/) | Dynamic programming: policy evaluation, policy improvement, policy iteration, and value iteration |
| [as_3](as_3/) | First-visit and every-visit Monte Carlo evaluation, plus on-policy Monte Carlo control |
| [as_4](as_4/) | Temporal-difference learning: TD(0), SARSA, Q-learning, and Expected SARSA |
| [as_5](as_5/) | Policy gradients: REINFORCE and REINFORCE with a learned value baseline |

## Environments

- **FrozenLake** — introductory environment interaction.
- **Fishlake** — a custom environment for dynamic programming and Monte Carlo methods.
- **Blackjack** — Monte Carlo prediction and control.
- **Cliff walking** — comparison of temporal-difference control methods.
- **CartPole** — neural policy-gradient experiments.

## Tools

Python, NumPy, SciPy, Matplotlib, Gymnasium, PyTorch, and Jupyter.
